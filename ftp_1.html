FTP SERVER

Esistono parecchi software FTP (come Filezilla Server).
Il software FTP Server mette a disposizione diverse operazioni come:

  • Download/Upload
  • Recupero trasferimenti interrotti
  • Rimozione e Rinomina file
  • Creazione directory
  • Navigazione directory

Il tipo di accesso mediante sistema di autenticazione mette a disposizione servizi e privilegi diversi.

FTP CLIENT

Anche l'FTP Client ha un proprio software che permette di connettersi a un server e caricare o effettuare il download da un file server.
solitamente è composto da una parte di comunicazione e dall'interfaccia.

Anche se i programmi sono diversi offrono delle funzioni comuni:

  • Connessione al server
  • Trasferimento dal server al client (metodo GET)
  • Trasferimento dal client al server (metodo PUT)
  • Lettura file di una directory del server (metodo DIR)
  • Cambio di directory (metodo CD)
  • Disconnessione dal server (metodo BYE)
