COSA E' IL PROTOCOLLO HTTP

Il protocollo HTTP è usato per trasmettere risorse, queste sono identificate da un URL che è composto da:

  • Protcollo
  • Host
  • Porta (nascosta o meno)
  • Percorso
  • File
  • Query e frammenti (eventuali)

In questo protocollo gli HTTP Client sono elementi attivi che richiedono risorse e ne visualizzano il contenuto.
Gli HTTP Server sono elementi passivi che rimangono in ascolto su una porta (default 80) e forniscono le risorse richieste.

Esistono 3 versioni del protocollo: 0.9, 1.0 e 1.1.

COME FUNZIONA IL PROTOCOLLO HTTP

Il protocollo per comunicare usa delle sessioni che iniziano stabilendo una connessione sulla porta, effettuando poi una richiesta che contiene un URL, quindi il Server restituisce la risorsa richiesta.

La connessione viene instaurata attraverso il 3WHS

Fino alla versione 1.0 il protocollo è senza memoria di stato.
La versione 1.1 permette una connessione PERMANENTE dove si possono effettuare più richieste durante la stessa sessione poichè la porta rimane aperta.
Infatti la versione 1.1 integra i livelli di sessione e presentazione (codifiche).

Esempio:

  • Il Client richiede una connessione (il Server è in attesa)
  • il Client invia la richiesta
  • il Server riceve la richiesta e invia la risposta
  • il Server chiude (o no) la connessione
  • il Client riceve la risposta ed eventualmente invia un altra richiesta

La versione 1.1 con pipeline (connsessione permanente incanalata) permette l'invio di un'altra richiesta anche prima dell'arrivo della risposta della richiesta precedente.
