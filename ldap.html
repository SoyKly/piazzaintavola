LDAP

Lightweight Directory Access Protocol è un sistema di gestione centralizzata di informazioni.
L'agettivo "Lightweight" indica che la progettazione del sistema privilegia le prestazioni essendo usato per ottenere riposte in tempi brevi nella ricerca e lettura dei dati a scapito della lentezza nelle operazioni di scrittura.

Gestisce i dati secondo una gerarchia ad albero, gli elementi dell'albero possono avere vari attributi e possono essere riferimenti a directory residenti in altri server LDAP, ogni elemento deve avere un nome unico.
