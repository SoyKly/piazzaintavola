COSA E' IL MODELLO CLIENT/SERVER

Il modello Client-Server è costituito da un insieme di host che gestiscono una o più risorse:

  • Server
  • Cllient

I client richiedono risorse dai server, che le gestiscono e distribuiscono.
Ogni processo server può diventare client per richiedere accesso a sua volta ad altre risorse gestite da processi server differenti.

Non sono gli host ad essere server o client ma i processi in escuzione su di essi, infatti un host può essere sia client che server in base ai processi in esecuzione.
